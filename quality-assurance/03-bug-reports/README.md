# Bug Reports

This directory contains defects discovered while testing KeyPilot.

Bug reports should use identifiers such as:

- `BUG-001`
- `BUG-002`
- `BUG-003`

Each report should contain:

- title;
- environment;
- severity;
- priority;
- preconditions;
- steps to reproduce;
- expected result;
- actual result;
- reproducibility;
- supporting evidence;
- current status;
- related regression test, where applicable.

Only genuine issues discovered during testing should be recorded as formal bug reports.
