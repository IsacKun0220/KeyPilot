# QA Evidence

This directory stores supporting evidence referenced by KeyPilot test cases and bug reports.

Suitable evidence includes:

- screenshots;
- short screen recordings;
- terminal output;
- automated test results;
- API response captures.

Recommended naming convention:

```text
BUG-001-step-removal.png
BUG-002-app-detection.mp4
TC-FUNC-006-config-persistence.png
automation-e2e-pass.png
```

Evidence should support a specific test or defect rather than being added only for presentation.
